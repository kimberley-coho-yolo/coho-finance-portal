# Coho Group Finance Portal

One stop shop for finance requests. Built with Jekyll and hosted free on GitHub Pages,
using the same design as the Technology Roadmap News / IT portal.

- **Request types, checklists and form links:** `_data/finance.yml`
- **Key dates:** `key-dates.md`
- **Site settings** (contact email, IT portal link): `_config.yml`
- **Page layout:** `index.html` (you shouldn't need to edit it)

Form links must be the "Collect responses > Copy link" version, never a link containing `Token=`.
